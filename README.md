# DrDerma.ai

DrDerma.ai is an AI-assisted dermatology web application that analyzes skin condition images and asks adaptive follow-up questions to improve diagnostic confidence.

The project combines image-based disease prediction with a dynamic clinical questionnaire system to simulate an intelligent triage workflow.

---

## 🌐 Live Demo

[Open DrDerma.ai](https://stately-strudel-38c0a0.netlify.app/)

⚠️ Backend may take a few seconds to wake up on first request because it is hosted on the free Render tier.
---

## 🚀 Features

* Upload skin condition images
* AI-assisted disease prediction
* Adaptive follow-up questioning
* Confidence-based diagnosis flow
* Clinical indicators section
* Medication suggestions
* Modern animated UI
* Responsive frontend design

---

## 🧠 How It Works

1. User uploads an image
2. Backend generates probable diseases
3. Adaptive questions are asked dynamically
4. Confidence scores are recalculated
5. Final diagnosis and recommendations are shown
